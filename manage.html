eBL Manuscript Metadata

Per-manuscript metadata used when exporting to the eBL corpus. The siglum eBL assigns is built from provenance.abbr + period.abbr + type.abbr + disambiguator and previewed in the rightmost column.

eBL Export

Configure the connection to the Electronic Babylonian Library and the target chapter for export. Writes require the write:texts scope.

No token
Token is stored locally in your browser only. On www.ebl.lmu.de, open DevTools, watch the Network tab while clicking around, and copy the Authorization: Bearer eyJ… value from any request to www.ebl.lmu.de/api.

Target chapter — corresponds to URL /corpus/{genre}/{category}/{index}/{stage}/{name}.
